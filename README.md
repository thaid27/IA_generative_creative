## 5. Tableau avantage inconvénient local vs cloud 


Avantages :
- Confidentialité des images générées 
- Accès aux modèles open source récents avant leur sortie sur les platformes en ligne
- Pipelines complexes avec des module d’analyse d’images (ControlNet, Segment Anything (SAM))
- Capacités d'automatisations (connexion LLM, exécutation à la chaine, réutilsiation des workflows)

Inconvénients :
- Limité par la puissance de la machine 
- Limites sur la rapidité, taille et qualité de modèle, résolution
